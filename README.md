# Bus Schedule

Довідкова система розкладу руху автобусів на автостанції (C++).
Командний проєкт для лабораторної роботи №4 з дисципліни «Основи систем контролю версій».

## Збірка та запуск

```bash
g++ -std=c++17 -Wall -o bus src/main.cpp
./bus
```

## Структура

- `src/` — вихідний код
- `data/` — файли з розкладом
- `tasks.md` — розподіл завдань
